# Início

Em caso de dúvidas, sinta-se livre para entrar em contato conosco por e-mail:

* Pedro Iori - [pedro\_iori@usp.br](mailto:pedro_iori@usp.br)
* Gabriel Galli Brandini - [gabrielgbrandini@usp.br](mailto:gabrielgbrandini@usp.br)

Para facilitar o uso do projeto desenvolvemos um TAD adicional, chamado de  `pipeline` , que engloba os outros TADs e oferece funções mais simples, sem que o usuário precise aprender o funcionamento exato de cada um deles. O usuário também pode consumir os outros TADs diretamente, se preferir, ignorando o TAD `pipeline` .

Seguindo os requisitos do projeto, para alterar entre os datasets das partes 1 e 2 basta escolher o reader correspondente - não há necessidade de alterar mais nenhum arquivo &#x20;
